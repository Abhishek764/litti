# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussion about the work. Harassment, discrimination, and personal attacks are not tolerated.

Report unacceptable behavior by opening a private report via GitHub's
"Report content" feature or by contacting the maintainers through a
[security advisory](https://github.com/Abhishek764/litti/security/advisories/new).
Maintainers will review every report and respond fairly.
